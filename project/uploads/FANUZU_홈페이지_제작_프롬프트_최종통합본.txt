FANUZU 반응형 홈페이지 제작 프롬프트 — 최종 통합본

FANUZU는 팬들의 시간과 행동을 기여로 전환하고, 그 기여를 통해 아티스트를 위한 팬덤 행성을 성장시키는 글로벌 K-POP 팬덤 플랫폼이다.

단순한 팬 커뮤니티, 투표 앱, 리워드 앱처럼 보이지 않도록 한다.
홈페이지 전체에서 다음 서비스 철학이 분명하게 전달되어야 한다.

팬들의 노력과 기여가 모일수록 아티스트를 위한 팬덤 행성은 더욱 크고 밝고 강하게 성장한다.
성장한 팬덤 행성은 아티스트를 위한 다양한 캠페인을 직접 개최하고 지원할 수 있는 힘이 된다.
팬의 모든 참여와 기여는 FANUZU PASSPORT에 기록되며, 사용자는 자신의 팬 활동이 사라지지 않고 하나의 역사로 남는다는 자부심을 느껴야 한다.

홈페이지는 모바일, 태블릿, 데스크톱에서 모두 자연스럽게 작동하는 반응형 원페이지 랜딩페이지로 제작한다.

────────────────────────────────────────
1. 핵심 콘셉트
────────────────────────────────────────

홈페이지의 중심 메시지는 다음과 같다.

나의 별을
이 우주에서
가장 밝게.

팬들이 걷기, 음악 감상, 콘텐츠 시청, 공유, 커뮤니티 활동, 기록, 캠페인 참여 등의 행동을 하면 기여가 쌓인다.

이 기여는 단순한 포인트가 아니라 다음과 같이 표현된다.

- 팬덤 행성의 크기
- 행성의 밝기와 광량
- 행성의 성장 단계
- 팬덤의 활성도
- 팬덤의 연결
- 팬덤의 역사
- 아티스트를 위한 캠페인 개최 및 지원 능력
- 사용자 개인의 FANUZU PASSPORT 기록
- 초기 참여자와 개척자의 영구적인 명예 기록

홈페이지는 기능을 설명하기만 하지 말고, 사용자가 직접 행동을 선택했을 때 행성이 밝아지고 성장하는 체험을 제공해야 한다.

전체 사용자 인식 흐름은 다음과 같아야 한다.

팬의 행동
→ POP으로 기록
→ 팬덤 행성 성장
→ 캠페인 개최 및 지원
→ 아티스트를 위한 실제 영향
→ 모든 기록이 FANUZU PASSPORT에 저장
→ 최초 참여자는 특별한 개척 기록과 칭호 획득

────────────────────────────────────────
2. FANUZU의 핵심 서비스 용어
────────────────────────────────────────

FANUZU

팬의 시간과 행동을 기여로 전환하고, 그 기여를 팬덤 행성의 성장과 아티스트를 위한 캠페인으로 연결하는 글로벌 팬덤 플랫폼.

POP

팬의 시간과 행동을 기록하는 FANUZU의 기여 포인트.

POP은 단순한 출석 포인트나 소비 포인트가 아니다.
걷기, 음악 감상, 콘텐츠 참여, 공유, 기록, 커뮤니티 활동, 캠페인 참여처럼 팬이 실제로 한 행동을 기여로 기록하는 단위다.

팬들의 POP이 모일수록 팬덤 행성은 더 크고 밝게 성장하고, 성장한 팬덤은 아티스트를 위한 다양한 캠페인을 직접 개최하고 지원할 수 있다.

FANUZU PASSPORT

PLANET FOUNDER

9. 팬 기여 체험 섹션
────────────────────────────────────────

사용자가 행동을 선택하면 행성이 밝아지는 인터랙티브 체험을 제공한다.

제목

오늘의 팬 활동 하나가
행성을 얼마나 밝힐까요?

설명

아래에서 오늘 한 행동을 선택해보세요.

작은 빛이 행성으로 모이고,
팬덤의 활력이 바로 달라집니다.

선택 버튼

음악을 들었어요        +8 POP
콘텐츠를 봤어요        +10 POP
소식을 공유했어요      +14 POP
팬과 대화했어요        +12 POP
추억을 기록했어요      +16 POP

각 버튼을 클릭하면 다음 효과가 나타나야 한다.

- 버튼 위치에서 행성 중앙으로 작은 빛 입자 이동
- 기여 점수 증가
- POP 증가
- 행성 밝기 증가
- 행성 광원과 그림자 증가
- 행성 크기 약간 증가
- 진행 바 증가
- 단계별 메시지 변경

단계별 메시지

초기

당신의 행성이 기다리고 있어요.
오늘의 작은 행동을 기여로 바꿔보세요.

1단계

행성이 천천히 깨어나고 있어요.
작은 기여가 빛의 시작이 됩니다.

2단계

당신의 기여가 행성을 밝히고 있어요.
꾸준한 행동이 팬덤의 활력이 됩니다.

3단계

이 행성은 이제 우주에서 눈에 띕니다.
함께 쌓은 기여가 가장 강한 빛이 됩니다.

행성 이미지 자체를 과도하게 확대하지 말고, 광량과 글로우 변화가 자연스럽게 보이도록 한다.

팬덤을 둘러싼 궤도를 만듭니다.

팬덤의 역사

컴백, 공연, 생일과 캠페인의 순간이
행성의 표면과 위성으로 남습니다.

데스크톱은 4열, 태블릿은 2열, 모바일은 1열로 구성한다.

11. 기여에서 캠페인으로 이어지는 핵심 섹션
────────────────────────────────────────

이 섹션은 FANUZU가 일반 팬덤 서비스와 다른 핵심이므로 강하게 표현한다.

제목

기여가 모이면 행성이 성장하고,
성장한 행성은 아티스트를 위해 움직입니다.

설명

팬들의 노력은 화면 속 점수로 끝나지 않습니다.

걷기, 스트리밍, 콘텐츠 활동, 공유와 기록으로 모인 기여는
팬덤 행성을 더 크고 강하게 성장시킵니다.

성장한 팬덤은 그 힘을 모아
아티스트를 위한 다양한 캠페인을 직접 만들고 지원할 수 있습니다.

세 단계 흐름

1단계: 팬의 기여

팬의 노력과 행동

걷기, 음악 감상, 콘텐츠 시청,
공유, 커뮤니티, 기록과 퀘스트 참여

2단계: 팬덤 행성 성장

팬덤 행성의 성장

기여가 쌓일수록 행성이 커지고 밝아지며,
새로운 궤도와 위성, 성장 단계가 열립니다.

3단계: 캠페인 개최와 지원

아티스트를 위한 행동

성장한 팬덤의 힘으로
컴백 응원, 생일 프로젝트, 광고, 기부,
기념 프로젝트와 팬덤 아카이브를
직접 개최하고 지원합니다.

세 단계 사이에는 빛의 선이나 화살표를 넣어 흐름을 연결한다.

팬의 기여
→ 팬덤 행성 성장
→ 캠페인 개최 및 지원
→ 아티스트를 위한 실제 영향

강조 문구

행성이 강해진다는 것은
팬덤이 아티스트를 위해 더 많은 일을 할 수 있다는 뜻입니다.

공식 명칭

ORIGIN 100

오리진 100

최초 행성 개척자

모든 행성에는
시작을 만든 팬들이 있습니다.

각 팬덤 행성의 생성을 가장 먼저 신청하고 함께한 100명에게
다시는 발급되지 않는 창립 칭호 ORIGIN 100을 부여합니다.

행성이 얼마나 크게 성장하더라도
누가 처음 그 별을 깨웠는지는 영원히 기록됩니다.

아직 아무도 발견하지 못한 별을
가장 먼저 깨우는 팬이 되어보세요.

ORIGIN 100으로 영원히 기록됩니다.

시간이 지나 수많은 팬이 이곳에 모이더라도
당신이 처음 이 행성을 밝힌 순간은 사라지지 않습니다.

아티스트 선택 또는 직접 입력

입력 항목

필수

- 개인정보 수집 및 이용 동의

선택

- 팬덤명
- 입덕 연도
- 추천인 코드

추천인 코드 입력란

추천인 코드가 있나요?
선택사항이며, 없어도 바로 사전등록할 수 있어요.

기본 상태는 접힌 형태로 표시한다.

+ 추천인 코드 입력

클릭하면 입력창이 열리도록 한다.

추천 코드가 URL에 포함된 경우 자동 입력한다.

예시

https://fanuzu.co.kr/?ref=A8K4D2

화면 안내

A8K4D2 팬의 초대로 참여합니다.

사용자가 원하면 추천 연결을 해제할 수 있게 한다.

추천 코드 형식

개인정보가 노출되지 않는 무작위 영문과 숫자 조합을 사용한다.

예시

FANUZU-A8K4D2
ORBIT-7KQ29P
STAR-X2M8LA

이메일, 실명, 전화번호는 추천 코드로 사용하지 않는다.

홈페이지 핵심 문구

혼자 시작해도 50 POP.
함께 시작하면 둘 다 100 POP.

또는 FANUZU다운 표현

혼자 별을 발견하면 50 POP,
함께 별을 밝히면 둘 다 100 POP.

POP 설명과 함께 사용하는 최종 문구

추천인 코드 없이 사전등록하면
나의 첫 기여로 50 POP이 예약됩니다.

추천인 코드와 함께 등록하면
나와 추천인 모두에게 100 POP이 예약됩니다.

POP은 팬의 시간과 행동을 기록하는 FANUZU의 기여 포인트입니다.

지급된 POP은 출시 후 팬덤 행성 성장과
아티스트를 위한 캠페인 참여에 사용할 수 있습니다.

코드 없이 등록하면
나에게 50 POP

작은 안내

17. POP 지급 조건 및 부정 이용 방지
────────────────────────────────────────

POP은 추천 코드를 입력하는 즉시 확정하지 않는다.

다음 조건을 충족한 뒤 지급한다.

- 신규 가입자의 이메일 인증 완료
- 만 14세 이상 확인
- 중복 이메일 및 중복 계정 제외
- 유효한 추천 코드
- 자기 추천 금지
- FANUZU 출시 후 최초 로그인 또는 계정 연동 완료
- 비정상적 가입, 자동화 가입, 허위 정보 입력 제외

안내 문구

POP은 이메일 인증 및 FANUZU 출시 후 최초 로그인 완료 시 지급됩니다.
중복 가입, 자기 추천, 허위 또는 비정상적인 가입은 지급 대상에서 제외됩니다.

추천인 코드 처리 규칙

- 추천 코드는 선택 입력
- 추천 코드가 없어도 사전등록 가능
- 한 사람당 하나의 추천 코드만 적용
- 등록 완료 후 추천인 변경 불가
- 자기 코드 입력 불가
- 존재하지 않거나 비활성화된 코드는 적용되지 않음
- 추천인 보상은 추천받은 사용자가 유효 가입 조건을 충족한 경우에만 확정
- 추천 수는 ORIGIN 100 순번에 영향을 주지 않음

추천 상태 표시

초대한 팬     7명
인증 완료     5명
확인 대기     2명

27. 애니메이션
────────────────────────────────────────

- 빛의 천천한 맥동

- 버튼 hover 시 약한 상승

- 기여 선택 시 빛 입자가 행성으로 이동
- 행성 밝기와 광량의 자연스러운 증가
- 진행 바 증가
- POP 숫자 카운트업
- PASSPORT 카드의 약한 홀로그램 광택

과도한 3D 회전, 빠른 움직임, 게임식 폭발 효과는 사용하지 않는다.

prefers-reduced-motion 사용자는 애니메이션이 최소화되도록 처리한다.

- 팬 행동 선택 시 POP 및 기여 점수 증가
- 입자가 행성으로 이동
- 행성 밝기와 성장 상태 변화
- POP이 팬의 시간과 행동을 기록하는 기여 포인트라는 점이 명확히 전달
- 팬 기여가 행성 성장으로 이어진다는 내용 표현
- 성장한 행성이 아티스트 캠페인을 개최하고 지원한다는 내용 표현
- FANUZU PASSPORT가 모든 참여 기록을 저장한다는 내용 표현
- PASSPORT 프리뷰 카드 표시
- PLANET FOUNDER와 ORIGIN 100의 차이 표현
- 각 팬덤 행성 최초 100명에게 ORIGIN 100을 지급하는 구조 표현
- 추천인 코드 선택 입력 가능
- 추천 코드 없이 등록 시 50 POP
- 추천 코드 입력 시 신규 가입자와 추천인 모두 100 POP
- 추천 코드 URL 자동 입력 지원
- 사전등록 완료 후 순번, POP 보상, 추천 코드, ORIGIN 100 여부 표시
- 추천 수가 ORIGIN 100 순번에 영향을 주지 않음
- 실제 아티스트 사진이나 공식 저작물 사용 없음
- 개인정보처리방침과 이용약관 연결
- 사전등록 폼 작동
- GitHub와 Vercel에 바로 배포 가능한 구조
- 전체적으로 저가형 게임 사이트가 아니라 프리미엄 글로벌 팬덤 서비스처럼 표현

────────────────────────────────────────
34. 홈페이지 전체 핵심 문장
────────────────────────────────────────

팬의 시간과 행동은 사라지지 않는다.

팬의 행동은 POP이 되고,
POP은 팬덤 행성을 성장시킨다.

성장한 행성은 아티스트를 위한
더 큰 캠페인과 행동을 가능하게 한다.

내가 보탠 모든 기여는
FANUZU PASSPORT에 기록된다.

행성의 시작을 함께한 최초의 100명은
ORIGIN 100으로 영원히 남는다.

추천인 코드 없이 시작하면 첫 기여 50 POP,
함께 시작하면 나와 추천인 모두 100 POP.

나의 별을,
이 우주에서 가장 밝게.
